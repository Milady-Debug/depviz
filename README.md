# depviz — визуализатор графа зависимостей Maven (вариант 13)

CLI-приложение на Python 3 (только стандартная библиотека).

## Запуск

```
python main.py [путь_к_конфигу.csv]     # по умолчанию config.csv
```

## Конфигурация (CSV)

| key          | описание                                                              |
|--------------|-----------------------------------------------------------------------|
| package_name | Maven: `groupId:artifactId[:version]`; тестовый режим: `A`, `B`, ...  |
| repository   | URL Maven-репозитория или путь к файлу тестового репозитория          |
| test_mode    | `true` — работа с тестовым файлом, `false` — с реальным репозиторием  |
| output_mode  | необязательный: `d2` (по умолчанию), `tree` или `load_order`           |

Относительный путь к тестовому репозиторию отсчитывается от папки конфига.
Примеры ошибочных конфигураций — в `configs/errors/`.

## Этап 2: прямые зависимости

Приложение скачивает POM-файл пакета (`urllib`), разбирает его (`xml.etree`)
и выводит прямые зависимости. Учитываются родительские POM, свойства `${...}`,
`dependencyManagement` и импорт BOM. Если версия не указана, берётся последняя
из `maven-metadata.xml`.

Для офлайн-проверки есть мини-зеркало `local_maven/` (URL `file:../local_maven`).

## Этап 3: граф зависимостей

Граф строится рекурсивным DFS (`depviz/graph.py`) с трёхцветной разметкой
узлов: встреча узла, который ещё в стеке рекурсии, означает цикл — он
фиксируется, а повторный обход не выполняется. Для Maven в граф попадают
транзитивные зависимости со scope `compile`/`runtime`, кроме `optional`.

Тестовый режим (`test_mode,true`): `repository` — путь к файлу вида

```
A: B C
B: D
D:
```

Примеры: `tests_repo/*.txt`, конфиги `configs/test_*.csv`.
Модульные тесты: `python -m unittest`.

## Этап 4: порядок загрузки

`output_mode,load_order` — вывод порядка загрузки: post-order DFS, т.е. каждая
зависимость стоит раньше пакета, который от неё зависит; корень — последний.
Сравнение с Maven и причины расхождений — в REPORT.md.

## Этап 5: визуализация (D2)

`output_mode,d2` — вывод описания графа на языке D2. Корень выделен цветом,
рёбра, замыкающие цикл, — красным пунктиром, недоступные пакеты — красной
пунктирной рамкой. Рендер: `python main.py configs/d2_simple.csv > g.d2 && d2 g.d2 g.svg`
(или вставить текст на https://play.d2lang.com). Готовые примеры — `examples/*.d2`.
